# Soru Takip · Eğitim Atölyesi

Eğitim Atölyesi'nin öğretmen/rehberlik soru sırası ekranı. Bu depo **sadece ekranı** (GitHub Pages) içerir;
öğrenci/öğretmen listeleri ve kayıtlar kurumun Google E-Tablosunda durur, burada **veri yoktur**.

Kaynak kod ve testler ayrı (gizli) depoda tutulur; bu klasör oradan `python tools/pages.py ../soru-takip` ile üretilir.
Elle düzenlemeyin.
